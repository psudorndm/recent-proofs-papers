We construct the first adaptively secure (epoch-based) batched identity-based encryption (BIBE) scheme from the learning with errors (LWE) assumption in the plain model. In addition to achieving adaptive security, we obtain significant efficiency improvements over existing lattice-based constructions. The public parameters, batch keys, and ciphertexts have sizes independent of the batch size, and setup requires no prescribed batch-size bound, unlike other lattice-based constructions. The authority generates batch keys from short, publicly computable digests. Encryption time is independent of the batch size, while decrypting an entire batch takes time linear in its size, including public preprocessing. We first give a plain-model generic construction from laconic function evaluation and tagged one-key functional encryption. Building on this generic construction, we then exploit the linear structure of laconic encryption to obtain a more efficient algebraic construction using tagged inner-product functional encryption. Using receiver non-committing encryption, we further obtain an adaptively secure variant in the random oracle model that avoids noise flooding in the laconic encryption component in our plain-model construction and permits a polynomial modulus-to-noise ratio for that component. Finally, we give a generic transformation from BIBE to threshold BIBE using threshold fully homomorphic encryption. The transformation preserves adaptive security against static corruptions and requires only one round of communication for batch-key generation after a trusted setup.
