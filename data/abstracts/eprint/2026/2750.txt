Fixed point multi-scalar multiplication (MSM) is a major computational component of pairing-based SNARK proof generation. The Luo--Fu--Gong (LFG) framework is a variant of Pippenger's bucket method that uses a multiplier set $M$ and precomputed point multiples to reduce the number of buckets and online point additions. For radix $q$ and a positive multiplier set $M$, covering all digit residues requires a bucket set of size at least $q/(2|M|)$. Previous constructions approaching this bound based on primitive roots or power-residue classes impose radix restrictions that exclude $q=2^c$, thereby requiring additional binary-to-radix conversion in software implementations. We present two main bucket set constructions for power-of-two radices $q=2^c$, using the multiplier sets $M=\{1,2,3\}$ and $M=\{1,3\}$, respectively. Their cardinalities are $q/6+O(\log q)$ and $q/4+2$, respectively, so both asymptotically attain the counting bound $q/(2|M|)$ while allowing efficient radix-digit extraction through shifts and masks. We further give two generalizations. Using consecutive powers of $3$ as multipliers yields bucket sets of size $q/(2\ell)+O(\log q)$ for every fixed positive integer $\ell$. For $\ell=2^d$ and $c\ge d+2$, consecutive odd multipliers yield bucket sets of size $q/(2\ell)+d+1$. We also present scalar conversion and two strategies for handling the leading digit, allowing the bucket set constructions to be used within the LFG framework.
